## Goal

Triage inbound lock-desk requests (lock, relock, reprice, extension) into auto-resolve or human-review lanes, cutting LO wait time and desk workload (cost reduction + delight).

**Primary actor:** Agent + Human-in-the-loop

## Trigger

New request hits /desk/lock-triage with a valid session token, OR new #lock-desk message tagged lock|relock|extend|reprice with an attached loan ID.

## Steps & tools

**Pattern:** ReAct (single-agent reason-act-observe loop)

| Step | Action | Tool / model | Guardrail |
|---|---|---|---|
| 1 | Step 1: Read request + pull loan snapshot from DESK. | desk.get_loan(loan_id): read-only. | Agent can READ DESK loan snapshots, OB pricing, and the eligibility KB. Agent can WRITE lock/extension actions to DESK (within thresholds) and to the analyst queue. Agent CANNOT edit margins/markups, override eligibility, or write to Encompass. |
| 2 | Step 2: Classify intent → lock / relock / extend / reprice / escalate. | ob.get_pricing(loan_id): read-only. |  |
| 3 | Step 3: Retrieve eligibility + current pricing (Optimal Blue). | desk.commit_lock(payload): write, requires confidence ≥ 80% and impact within threshold. |  |
| 4 | Step 4: Score impact (bps + $) and confidence. | desk.submit_extension(payload): write, requires confidence ≥ 80%. |  |
| 5 | Step 5: If in-bounds → execute via DESK; else route to analyst queue + log outcome, confidence, and impact to eval store. | queue.escalate(payload): write, no confidence gate. |  |

**Schemas**

ob.get_pricing → {rate, price, bps_delta, eligible:bool, product}. desk.commit_lock → {lock_id, status, price}. queue.escalate → {ticket_id, lane}.

**Memory (in or out of scope)**

- **Episodic:** In-scope: tool results within a single run (snapshot, pricing pull, classification). Lifetime: end of run.
- **Semantic:** In-scope: pricing/eligibility rules taxonomy + analyst's preferred summary format, lifetime indefinite. Out of scope: do NOT persist borrower PII or rate-lock history beyond the run.
- **Working:** Current loan ID, request type, LO identity, retrieved pricing + eligibility chunks. Working context only.
- **External:** DESK (read snapshot / write lock actions), Optimal Blue (read pricing/eligibility), eligibility KB (read), analyst queue (write).

## Human-in-the-loop

Lock desk analyst approves any lock/relock with price impact > 25 bps or dollar impact > $2,500. Analyst also reviews when classifier confidence < 70%, or when the loan is Bond/HFA.

## Success & failure

- **Done when:** Success: action committed + confirmation rendered to LO. Failure: 2 pricing/tool errors in a run → escalate. Escalation: confidence < 70%, impact over threshold, or Bond/HFA → analyst queue. Timeout: 45s wall clock → abort and hand back.
- **Fails safe when:** Agent can READ DESK loan snapshots, OB pricing, and the eligibility KB. Agent can WRITE lock/extension actions to DESK (within thresholds) and to the analyst queue. Agent CANNOT edit margins/markups, override eligibility, or write to Encompass.
